# 微信4.1.0版本小程序调试支持

## 简介

这个目录包含了对微信4.1.0版本的小程序调试支持。根据微信更新日志，微信4.1.0是一个重大版本更新，包含了许多新功能，因此可能需要更新Hook地址以支持小程序调试。

## 支持的版本

- 微信Windows版本: 4.1.0
- 对应的小程序内部版本: 13080813 (假设值，需要根据实际测试调整)

## 使用方法

### 方法一：使用新版本支持工具

1. 确保你已经安装了微信4.1.0版本
2. 运行调试工具:
   ```
   cd new_version_support
   python main.py -x
   ```
3. 工具会自动检测微信版本并应用相应的Hook配置

### 方法二：使用原有工具

1. 确保你已经安装了微信4.1.0版本
2. 运行调试工具:
   ```
   cd ..
   python main.py -x
   ```

## 配置文件说明

- `configs/address_13080813_x64.json`: 微信4.1.0对应的小程序Hook地址配置
- `scripts/hook.js`: 更新后的Hook脚本，增加了对新版本的支持

## 新工具特性

- 自动检测微信和小程序进程
- 更友好的错误提示
- 支持多版本配置管理
- 更稳定的注入机制

## 注意事项

1. 由于微信4.1.0是较新版本，Hook地址可能需要根据实际测试进行调整
2. 如果发现无法正常工作，请检查微信的实际小程序版本号
3. 可能需要使用调试工具来查找新的Hook地址
4. 建议以管理员权限运行工具
