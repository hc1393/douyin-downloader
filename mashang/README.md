# 第十题解决方案

这个项目是针对"马上拍"平台第十题的自动化解决方案，包括数据抓取和自动提交功能。

## 功能特点

1. 多线程并发获取题目数据
2. 自动计算所有页面数据总和
3. 自动提交答案到服务器
4. 错误处理和异常情况处理

## 使用方法

```bash
python 第十题.py
```

## 代码说明

- `第十题.py` - 主程序，包含数据抓取、计算和提交逻辑
- `第十题加密.js` - 包含生成请求参数所需的加密算法

## 工作流程

1. 程序会并发请求20页数据
2. 计算所有页面数据的总和
3. 自动将结果提交到服务器
4. 显示执行结果和耗时统计
