# 人脸识别可视化系统

这是一个基于Python和OpenCV的人脸识别系统，具有友好的图形用户界面。

## 功能特性

### 🎯 核心功能
- **实时人脸检测**: 使用Haar级联分类器进行人脸检测
- **人脸识别**: 基于LBPH算法的人脸识别
- **人脸注册**: 支持添加新的人脸数据
- **模型训练**: 自动训练人脸识别模型
- **实时预览**: 实时显示摄像头画面和检测结果

### 🖥️ 用户界面
- **现代化GUI**: 基于PyQt5的直观界面
- **多标签页设计**: 分别管理识别、训练和设置
- **实时反馈**: 显示识别结果和系统日志
- **参数调节**: 可调节检测参数和摄像头设置

## 使用指南

### 基本人脸识别流程

1. **启动系统**
   - 运行程序后会显示主界面
   - 点击"开始摄像头"按钮启动摄像头

2. **添加人脸数据**
   - 切换到"模型训练"标签页
   - 在"姓名"输入框中输入要注册的人员姓名
   - 点击"开始录入"按钮
   - 确保摄像头能清楚拍摄到人脸

3. **训练模型**
   - 录入足够的人脸数据后
   - 点击"训练模型"按钮
   - 等待训练完成

4. **进行识别**
   - 返回"人脸识别"标签页
   - 系统会自动识别摄像头中的人脸
   - 显示识别结果和置信度

### 参数设置

在"系统设置"标签页可以调整：
- **缩放因子**: 影响检测精度和速度
- **最小邻居**: 控制检测严格程度
- **摄像头索引**: 选择不同的摄像头设备
- **帧率**: 设置视频显示帧率

## 技术特点

### 人脸检测
- 使用OpenCV的Haar级联分类器
- 支持实时人脸检测
- 可调节检测灵敏度

### 人脸识别
- 采用LBPH（局部二值模式直方图）算法
- 支持多人脸数据库管理
- 提供置信度评估

### 界面设计
- 响应式布局设计
- 实时视频流显示
- 直观的操作反馈

## 注意事项

1. **摄像头权限**: 确保程序有访问摄像头的权限
2. **光照条件**: 良好的光照有助于提高识别准确率
3. **人脸清晰度**: 保持人脸正对摄像头，避免遮挡
4. **训练数据**: 建议每人录入5-10张不同角度的照片

## 故障排除

### 常见问题

1. **无法打开摄像头**
   - 检查摄像头是否被其他程序占用
   - 尝试更改摄像头索引值
   - 确认系统摄像头驱动正常

2. **检测不到人脸**
   - 调整缩放因子和最小邻居参数
   - 改善光照条件
   - 确保人脸完整出现在画面中

3. **识别准确率低**
   - 增加训练样本数量
   - 确保训练时人脸清晰
   - 重新训练模型
