# 红蚂蚁数藏项目

这是一个用于红蚂蚁数字藏品平台的自动化工具集，包含登录、合成、购买等功能。

## 功能特性

1. **账号管理**
   - 批量登录获取Token
   - Token刷新和管理

2. **合成操作**
   - 多线程合成任务
   - 可调节线程数量

3. **商品详情获取**
   - 查询商品详细信息

4. **购买操作**
   - 支持批量购买
   - 定时抢购功能

## 文件说明

- `抢购多线程.py`: 核心功能模块，包含登录、合成、购买等API接口调用
- `gui界面.py`: 图形用户界面程序，提供可视化操作
- `获取商品详情.py`: 商品详情查询工具
- `账号.txt`: 账号信息存储文件（账号——密码——token格式）

## 使用方法

1. 在`账号.txt`中填写账号信息，格式为：
   ```
   账号——密码——token
   ```
   或
   ```
   账号——密码
   ```

2. 运行`gui界面.py`启动图形界面程序，或直接运行`抢购多线程.py`使用命令行版本

3. 首次使用建议先执行登录功能获取Token

## 注意事项

- 请合理设置线程数，避免对服务器造成过大压力
- 遵守平台使用规则，避免账号被封禁
- 定期更新Token以保证功能正常使用
