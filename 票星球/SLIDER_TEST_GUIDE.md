## 测试方法

要测试模块是否正常工作，请按照以下步骤操作：

1. 准备一张滑块验证码图片
2. 运行GUI程序：
   ```
   python slider_gui.py
   ```
3. 在界面中点击"加载背景图像"按钮，选择您的验证码图片
4. 点击"检测滑块距离"按钮查看识别结果

## 常见问题及解决方案

### 1. 无法读取图像文件
- **问题**：提示"无法读取图像文件"
- **解决方案**：
  - 确保图像文件路径正确
  - 检查图像文件格式是否支持（支持PNG、JPG、JPEG、BMP、TIFF）
  - 确保图像文件未被其他程序占用
  - 检查文件权限是否正确

### 2. 图像识别准确率低
- **问题**：识别结果不准确
- **解决方案**：
  - 调整参数设置（最小面积、最大面积等）
  - 尝试不同的检测方法
  - 使用图像编辑工具预处理图像，提高对比度

### 3. 模板匹配方法无法使用
- **问题**：使用模板匹配方法时报错
- **解决方案**：
  - 确保提供了正确的模板图像文件
  - 模板图像应命名为"gap_template.png"并放在同一目录下

## 模块功能说明

### 基础模块 (slider_captcha_solver.py)
- 提供基本的滑块验证码识别功能
- 支持简单的特征分析方法
- 包含结果可视化功能

### 高级模块 (advanced_slider_solver.py)
- 提供更高级的图像识别算法
- 支持多种边缘检测方法（Canny、Sobel、Laplacian）
- 支持特征分析和模板匹配两种方法
- 提供更精确的识别结果

### GUI模块 (slider_gui.py)
- 提供图形用户界面
- 支持参数调整
- 实时显示识别结果
- 可视化处理过程

## 使用建议

1. 对于初学者，建议先使用GUI界面进行测试
2. 根据不同的验证码类型，调整参数以获得最佳效果
3. 如果特征分析方法效果不佳，可尝试准备模板图像使用模板匹配方法
4. 复杂的验证码可能需要进一步优化算法
